# Round-robin check-in

Every agent with responsibilities toward others keeps contact with each of them on every cycle, so no connection goes idle and no part of the network is lost over time.

## Procedure

1. List the agents you have responsibilities toward (peers or subordinates).
2. For each one, send a real message: a question, a status request, or a result to pass on.
3. Record each contact in the cycle's artifact.

## Never

- Never end a cycle with "quiet tick, nothing to do." If there is nothing to report, send a question that moves the work on.

## Checks

- Every agent you have responsibilities toward has a contact recorded for this cycle.
- Each contact is a question, a status request, or a result, not an empty status.
